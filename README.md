# MINX IN MOTION

The cinematic portfolio of Minx (Thawtar San), a freelance video editor and content creator based in Yangon, Myanmar.

## GitHub Pages

This is a ready-to-publish static website. The `index.html` file is at the repository root, so GitHub Pages can publish the repository directly from the `main` branch and root folder.

## Local preview

Open `index.html` in a browser, or serve this folder with any static web server. The site includes its original responsive layout, cinematic scrolling, opening identity, Motion control, project gallery, real playable videos, portraits, contact links, and social links.

## Media

All media required by the current portfolio is included locally: eight portraits, ten complete project videos, previews, posters, and scrub frames. The project titles and descriptions are based on Minx's supplied work and source material.

## Publishing

In GitHub, open **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save. The published address will be:

`https://oasix-yewintthu.github.io/minx-in-motion/`

No server, database, API key, or environment variable is required.
